# Customer Churn Analysis Dashboard

This project analyzes telecom customer churn using Microsoft Excel.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Data Visualization

## Key KPIs
- Total Customers
- Active Customers
- Churn Customers
- Churn Rate

## Dashboard Analysis
The dashboard analyzes customer churn based on:
- Contract Type
- Monthly Charges
- Customer Tenure
- Customer Risk Level

## Key Insights
- Month-to-month contract customers have the highest churn.
- Customers with higher monthly charges churn more frequently.
- Approximately 26% of customers have churned.
